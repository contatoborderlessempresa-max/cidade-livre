# Cidade Livre 🏙️

Jogo 3D de mundo aberto estilo sandbox, feito para meu filho — rodando no navegador e como app Android. Um arquivo HTML único com three.js, sem engine, sem assets externos: todos os modelos, sons e texturas são gerados por código.

🎮 **Jogar agora:** https://SUA-URL.vercel.app

## Destaques

- Cidade procedural + pontos reais de Caruaru-PE: Shopping Caruaru, Estação do Forró (com trio de forró e bandeirinhas), Praça do Rosário, Gracie Barra, Bonanza, e os bairros Indianópolis, Maurício de Nassau e Salgado
- 10+ veículos: carros, moto, bicicleta, skate com manobras, helicóptero, jatinho, balão, jetski, lancha e iate
- Física: relevo dirigível na serra, rampas gigantes, gravidade, futebol de carro no estádio
- Sistema estilo Minecraft: minerar, demolir e construir com blocos em qualquer prédio
- Economia infantil: trabalhos (táxi, pizza, caixa, garçom), fazenda de plantar/colher/vender, compras
- Torre B-TECH com elevador funcional, escadas rolantes e heliponto pousável
- Luta de jiu-jitsu por pontos com progressão de faixas
- Sons 100% sintetizados via WebAudio + vozes dos personagens com TTS pt-BR
- **Multiplayer online** via Supabase Realtime: salas por código secreto, avatares com nome e chat falado
- App Android via Capacitor, 100% offline (exceto o modo online)

## Stack

three.js · WebAudio API · Web Speech API · Supabase Realtime · Capacitor · Vercel

## Rodar

Abra `cidade-livre-v21.html` no navegador (desktop ou celular deitado). Para o online, crie um projeto no Supabase e preencha `SUPA_URL` e `SUPA_KEY` no topo do arquivo.
